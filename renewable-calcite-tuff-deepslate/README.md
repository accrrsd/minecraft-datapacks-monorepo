# minecraft-renewable-things

Stop treating Calcite, Tuff, and Deepslate as non-renewable resources. This data pack provides a balanced, vanilla-style solution to obtain these blocks without scarring the environment with massive strip mines, or make it accessable in sky block or factory-like game.

- Calcite: 1 Water Bucket + 8 Bone Blocks = 8 Calcite
- Tuff: 1 Lava Bucket + 8 Dirt = 8 Tuff
- Deepslate: 1 Lava Bucket + 8 Cobblestone = 8 Deepslate
