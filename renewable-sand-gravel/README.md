# minecraft-renewable-things

This data pack adds balanced recipes to craft Sand and Gravel. Say goodbye to the tedious and glitchy End Portal sand duping meta! This data pack provides a balanced, legitimate way to automate and craft essential building materials.

Recipes:
  - Sand: Gravel + 1 Iron Nugget = Sand
  - Gravel: Cobblestone + 1 Iron Nugget = Gravel

Perfect for technical players, Skyblock enthusiasts, and anyone who prefers legitimate automation over exploits.
